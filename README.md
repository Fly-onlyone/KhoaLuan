# Khóa luận tốt nghiệp: Tiền xử lý dữ liệu cho bài toán phân loại và phân cụm

Repo này lưu trữ các notebook và tài liệu phục vụ khóa luận tốt nghiệp, tập trung vào việc nghiên cứu và ứng dụng **tiền xử lý dữ liệu** trong các bài toán **phân loại** và **phân cụm**.

## Giới thiệu

Nội dung repo tập trung vào hai hướng chính:

- **Phân loại dữ liệu**
- **Phân cụm dữ liệu hành vi người dùng**

## Nội dung chính

### 1. Bài toán phân loại
Notebook `Cora_Classification_FINAL.ipynb` tập trung vào bài toán phân loại dữ liệu, bao gồm:

- xử lý dữ liệu đầu vào
- lựa chọn đặc trưng
- chuẩn hóa dữ liệu
- huấn luyện và đánh giá mô hình
- so sánh kết quả giữa các cách tiếp cận khác nhau

### 2. Bài toán phân cụm
Notebook `users_behavior_Clustering_FINAL.ipynb` tập trung vào:

- phân tích dữ liệu hành vi người dùng
- tiền xử lý dữ liệu
- áp dụng thuật toán phân cụm
- trực quan hóa cụm dữ liệu
- đánh giá chất lượng phân cụm
